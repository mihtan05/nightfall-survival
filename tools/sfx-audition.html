Nghe thử âm thanh — Nightfall: Survival

Đang nạp…

Mỗi sự kiện có 2–4 ứng viên. Bấm ▶ để nghe, chọn nút tròn cho bản thắng. Bản chọn sẵn là dự đoán từ số đo (âm phát dày thì ưu tiên ngắn, không đuôi dài) — hoặc bản đang dùng trong game nếu có tools/sfx-pick.json. Cột: thời lượng (giây), đỉnh, độ to (RMS lớn nhất trong 100 ms, dBFS). Chạy qua máy chủ: python -m http.server 8765 rồi mở /tools/sfx-audition.html. Cần thư mục vendor/audio/ (xem CREDITS.md).

Kết quả

Dán khối JSON vào tools/sfx-pick.json rồi chạy python -I tools/sfx_import.py để chép/chuyển file vào assets/sfx/ và in khối SFX_FILES.
